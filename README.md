## Estado da revisão
Os arquivos identificam mudanças efetivamente verificadas, como a correção para **Resolução nº 18/1989**, ajustes de cronograma de novembro e o conteúdo específico de PL.AL.070. **Não constituem ainda leitura integral e consolidação de todas as retificações ou auditoria das 1.285 páginas de apostilas e cadernos privados.** Informações em análise devem ser conferidas no edital vigente.

## Direitos autorais e proteção de dados
Este repositório é público. Não contém cópias de apostilas comerciais nem dados pessoais expostos em marcas d'água. As apostilas originais permanecem apenas no ambiente privado de estudo. Os documentos oficiais são consultados pelos links da organizadora.

## Objetivo
Evoluir para matriz rastreável: concurso → cargo completo → disciplina → tópico → fonte oficial → retificação → material revisado → questões e revisões.
